# **App Name**: Echoes of Time

## Core Features:

- Image Upload and Display: Allow users to upload JPG and PNG images, displaying the original in the 'The Original Memory' panel.
- Automatic Restoration: Utilize the Gemini 2.5 Flash Image API to automatically restore uploaded photos, correcting damage, color, and clarity based on the prompt. This restored image becomes the 'Restored Master Image'.
- Restored Image Display: Display the restored image as the first image in the 'The Echo Chamber' panel.
- Re-imagination Controls: Provide control buttons below the restored image to trigger re-imagination features.
- AI-Powered Re-imagination: Call the Gemini 2.5 Flash Image API to generate new images based on user-selected re-imagination prompts (Show Another Moment, Generate a Subtle Smile, Create a Different Pose, Widen the Scene), using the 'Restored Master Image' as a reference tool for character consistency.
- Gallery Display: Present all generated images in a gallery or carousel format in the 'The Echo Chamber' panel.

## Style Guidelines:

- Background: Off-white (#FAF9F6) to provide a clean, vintage-inspired canvas.
- Primary: A desaturated brown (#A69A8B) for buttons and key UI elements. The hue aligns with vintage themes without being cliché, reminiscent of aged paper.
- Accent: A lighter brown (#C4B7A3), used for interactive elements.
- Headline font: 'Literata', a transitional serif with a literary and vintage feel.
- Two-panel vertical split layout: 'The Original Memory' panel on the left, 'The Echo Chamber' panel on the right.
